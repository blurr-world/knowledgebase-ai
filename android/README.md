\# Android — KnowledgeBase AI



Android client for uploading PDFs and asking AI-powered questions about document content.



\## Tech Stack



\- Kotlin

\- XML layouts

\- Android Studio

\- Retrofit and Gson



\## Setup



1\. Open the `android/` directory in Android Studio.

2\. Allow Gradle to sync and download dependencies.

3\. Configure the API base URL to point to your running backend or deployed Render service.

4\. Run the app on an emulator or Android device.



\## Features



\- User registration and login

\- PDF upload and selection

\- AI-powered document Q\&A

\- Document listing and deletion

\- JWT-based API authentication



\## Notes



\- Ensure the backend is accessible from the device.

\- Keep API credentials and signing keys out of version control.
