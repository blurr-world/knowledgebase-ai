# \# Backend — KnowledgeBase AI

# 

# FastAPI backend for authentication, PDF document management, and AI-powered question answering.

# 

# \## Tech Stack

# 

# Python · FastAPI · SQLAlchemy · MySQL · JWT · Qdrant Cloud · Filebase · OpenRouter

# 

# \## Setup

# 

# 1\. Create and activate a Python virtual environment.

# 2\. Install dependencies:

# 

# &#x20;  ```bash

# &#x20;  pip install -r requirements.txt

# &#x20;  ```

# 

# 3\. Configure the required environment variables in `.env`.

# 4\. Start the development server from the `backend/` directory:

# 

# &#x20;  ```bash

# &#x20;  uvicorn app.main:app --reload

# &#x20;  ```

# 

# \## API Documentation

# 

# When the server is running, visit:

# 

# \- Swagger UI: `/docs`

# \- Health check: `/`

# 

# \## Deployment

# 

# Configure the required environment variables and deploy the backend to Render.

# 

# \*\*Note:\*\* Never commit `.env` files, credentials, or secret keys.
